# Panel de Cobranzas — Ingresos reales de prestadores turísticos

Panel interactivo de evolución mensual de ingresos (Administración de Parques Nacionales · Dirección de Concesiones).

## Cómo publicarlo en GitHub Pages (todo desde el navegador, sin instalar nada)

1. **Crear cuenta / iniciar sesión** en https://github.com (es gratis).

2. **Crear un repositorio nuevo:**
   - Arriba a la derecha, tocá el `+` → **New repository**.
   - En *Repository name* escribí, por ejemplo, `panel-cobranzas`.
   - Marcá **Public** (Pages gratuito requiere repositorio público).
   - Tocá **Create repository**.

3. **Subir el archivo `index.html`:**
   - En la página del repositorio recién creado, tocá **uploading an existing file** (o **Add file → Upload files**).
   - Arrastrá el archivo **`index.html`** (el que está en esta carpeta).
   - Abajo, tocá **Commit changes**.

4. **Activar GitHub Pages:**
   - En el repositorio, entrá a **Settings** (Configuración).
   - En el menú izquierdo, tocá **Pages**.
   - En *Branch*, elegí **main** y carpeta **/ (root)**, y tocá **Save**.

5. **Listo.** Esperá 1–2 minutos y recargá esa misma página de *Pages*: va a aparecer el enlace
   `https://TU-USUARIO.github.io/panel-cobranzas/`
   Ese link abre el panel en cualquier celular o computadora, con toda la interactividad funcionando.

## Notas

- El archivo es autónomo: los datos y la lógica están embebidos. Solo la tipografía se toma de Google Fonts (si no hay conexión, usa una fuente del sistema parecida).
- Para **actualizar** el panel más adelante, subí un nuevo `index.html` al mismo repositorio (Add file → Upload files → Commit). El sitio se actualiza solo en 1–2 minutos.
- El repositorio es público, pero solo verá el panel quien tenga el enlace. Si necesitás acceso restringido, se puede usar otra plataforma con control de acceso.
